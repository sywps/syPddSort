## 开局设计

- 小柴犬：16×15，保留黑色脸部轮廓、眼鼻及粉色舌头；橙白各48颗连通色块互换。轮廓可辨，主要学习两色腾位。区别于v1保留大图只减少错位，这里图案总规模已经下降。
- 向日葵：20×22，保留图库已有的局部错位设计。大花盘与叶片明确，沿用其144颗错位，不重新随机打散。增加一种待操作颜色与处理量。
- 爱心：18×18，保留白色分隔线；粉、紫、深红各36颗按三色循环，再交换外层两片各36颗。让轮换关系比简单两色互换多一步，避免把图案全部打散。

三关均使用普通难度标记Hard=0、单次最多12颗；不继承图库的0秒计时、特殊规则或来源运行时字段。目标矩阵采用图库已转换的本项目20色体系。容量没有超过每关待归位量，仍需要及时给带上的豆腾出目标位置。

## 试玩

打开 http://localhost:8080/tools/generated_levels/retention-v2/ 。每关可查看旧图、新图、新开局并试玩。

若打开的是UI Preview，点击“进入 Game.scene”。外部关卡不运行主线引导/DDA；第三关默认72容量，额外的level_3_expanded.json供体验免费引导后的84容量，正式接入应使用level_3.json，避免重复+12。

## 验证与边界

generate.cjs复用v1的源码加载器与连通区工具，检查尺寸、颜色守恒、空格位置和合法解。verify.cjs复用现有PvpBotReplay策略，仅在验证沙盒中把构造参数改为主线实际20载体；不修改游戏规则源码。两种策略评分、10个种子，各候选10/10通关；第三关72及84均通过。mainline_solution_N.json提供0起始行列操作参考。

容量60对照同样10/10通关；不能由此宣称扩容已提高胜率，且容量参与种子哈希，不应拿两组机器人耗时当配对因果实验。机器人仅证明规则可解，不等于真人难度、真机性能、留存或广告收益。

浏览器360px预览已逐关检查新图案与容量，并点击验证豆豆上带，分别显示12/72、12/84、12/96。未执行三关真人完整通关或真机性能测试。

原正式29关仍有同款柴犬，正式接入时需一起处理后续图案重复（例如交换顺序）；本候选阶段没有擅自修改29关。来源与SHA256记录在manifest.json。

建议先按3→4→5连续试玩，观察辨认、腾位、等待和重复点击，再决定是否接入实验桶；后续以新玩家5关完成率、下一关进入率、次日留存、每新增玩家累计广告完成和收入共同判断。此版没有新增广告压力点。
