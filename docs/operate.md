# 轻松拼豆素材投放运营 SOP

> 版本：2026-06-25  
> 适用：`轻松拼豆 / 拼豆豆` 微信小游戏朋友圈广告素材运营  
> 目标：让 Codex 作为 AI 运营，自动完成素材诊断、竞品对照、测试建议和下一批素材生成文案；真人只负责 Codex 暂时无法直接执行的外部动作。

## 1. 运营目标

本 SOP 里的“运营”默认指 Codex 这个 AI 运营，不是指真人运营。真人只在 Codex 受限时补充输入，例如导出老后台 Excel、把提示词拿去生成图片、上传广告后台、提供登录态页面截图。

本 SOP 不把素材运营理解为“做几张好看的图”。它的目标是建立一套可重复执行的素材生产和投放判断流程：

1. 每天知道哪些老素材应该放量、保留、复测或暂停。
2. 每天知道下一批应该生成哪些素材，且每张素材都有明确目标用户和画面标准。
3. 每天能解释竞品热门素材为什么值得借鉴、为什么可能误导。
4. 每天用相同指标口径判断素材，不靠主观审美拍脑袋。

当前已知用户画像：女性约 87%，30-50 岁约 75%。因此素材默认服务“成年女性休闲、手作、整理、配色、解压、轻挑战”人群，不默认服务强竞技、硬核益智或年轻潮流用户。

## 2. Codex 的输入和真人兜底

Codex 优先使用已经抓到的历史数据、素材文件、竞品素材和当天导出的 Excel 自动分析。真人不是去做标签和判断的人，真人只补充 Codex 不能直接拿到的文件或执行外部平台动作。

| 输入 | 来源 | 必需字段 | 备注 |
| --- | --- | --- | --- |
| 我方投放数据 | Codex 抓取结果或后台 Excel | 日期、广告位、计划名、素材 ID、消耗、ROI、曝光、点击、转化、更新时间 | 优先使用 Codex 已抓目录；老后台断连时由真人导出 Excel |
| 我方素材文件 | Codex 下载目录或后台素材包 | 图片/视频原文件、素材 ID | Codex 已下载过的素材不需要真人重复准备 |
| 竞品素材 | Codex 抓取结果或 AdXray 导出 | 标题、图片、出现/抓取次数、关联计划数、使用天数 | 竞品没有 ROI，只作为创意热度参考 |
| 游戏内数据 | 自有报表或导出文件 | 首局进入、首局通过、首日广告展示、广告收入、D1 留存 | 没有时 Codex 先用广告后台 ROI 代替 |

## 3. 每日执行流程：Codex 自动跑

### 3.1 Codex 数据更新

1. Codex 优先读取已有抓取目录和当天 Excel。
2. Codex 自动筛选广告位 `P`，日期默认最近 7 天。
3. Codex 自动关联素材 ID、计划名、消耗、ROI、曝光、点击、转化和本地素材文件。
4. Codex 自动给每个素材打标签：素材类型、核心画面元素、文案承诺、目标用户、主要风险、下一步动作。
5. 如果浏览器登录态或后台限制导致 Codex 无法继续下载，真人只需要导出 Excel 或下载素材包，不参与分析判断。

### 3.2 启动 Codex 的话术

每天只要对 Codex 说：

```text
请按 docs/operate.md 跑今天的素材投放 SOP。
优先使用当前 temp 目录里已经抓到的我方素材、投放数据和竞品素材。
如果当天我补了 Excel 或新素材目录，请同时合并进去。
请输出：
1. 今天要放量/保留/复测/暂停的素材清单；
2. 每个判断的指标依据；
3. 竞品可借鉴点和风险；
4. 明天要生成的素材 brief 和提示词；
5. 每个新素材对应的测试计划。
```

### 3.3 真人只执行 Codex 无法直接执行的外部动作

1. Codex 给出素材组、提示词、负面提示、测试目标和计划名。
2. 真人把提示词拿去生成图片或视频。
3. 真人把素材上传广告后台。
4. 真人把生成后的素材文件和计划 ID 回传给 Codex。
5. Codex 次日自动复盘，不要求真人手工打标签。

### 3.4 次日：复盘

1. 不看单个指标，必须同时看 CTR、CPA、ROI、样本量。
2. 高 CTR 低 ROI 的素材先判为“吸错人”或“承诺不匹配”，不要直接放量。
3. 高 ROI 小样本只能复测，不能直接大幅加预算。
4. 连续两天低 ROI 且有足够消耗的素材暂停。

## 4. Codex 自动标签体系

每个素材必须打这些标签，但标签由 Codex 自动判断。真人不需要手工填写，最多在 Codex 判断不准时纠偏。

| 字段 | 示例 | 用途 |
| --- | --- | --- |
| 素材类型 | 九宫格图、竖版视频、玩法录屏、手作场景图 | 用于同类型对比 |
| 核心画面元素 | 拼豆盒、色块、手部操作、成品图案、游戏 UI、挑战文案 | 判断素材吸引什么人 |
| 文案承诺 | 解压、上头、挑战、整理、成品满足、第一关测试 | 判断是否和游戏体验匹配 |
| 目标用户 | 手作熟悉用户、整理控、配色审美用户、轻挑战用户、真实玩法用户 | 判断投来的人是否可能变现 |
| 主要风险 | 像电商材料、像涂色书、像纹身图、IP 风险、玩法不清楚 | 判断是否容易误吸 |
| 下一步动作 | 放量、保留、复测、改图、暂停 | 投放执行 |

## 5. 画面元素标准

### 5.1 当前正向元素

从当前已抓我方素材和竞品素材看，优先测试这些元素：

1. 干净九宫格：3x3 分区清楚，每格颜色饱满，远看一眼能懂“分类、整理、配色”。
2. 拼豆质感：珠子有孔洞、圆角、轻微高光，不能像普通糖果或积木。
3. 色彩秩序：每格主色明确，最好有渐变、冷暖对比或彩虹序列。
4. 成品期待：能看到花朵、角色、图案、装饰画等完成结果。
5. 手部动作：镊子、手指、取豆、放豆，能解释“这是可操作的小游戏”。
6. 轻挑战文案：比如“这关你能过吗”“第一关别卡住”，但不能把画面做得太难。

### 5.2 当前负向元素

这些元素需要谨慎：

1. 只像收纳盒或材料商品，没有游戏感，容易吸引买材料的人。
2. 过多灰线、空格、半透明盒边，远看杂乱。
3. 只有漂亮成品，没有操作、目标或玩法提示。
4. 明确 IP 角色、商标角色、名画原图，存在版权和审核风险。
5. 过度困难、失败、槽位爆满的画面，会带来低质量好奇点击。

### 5.3 好九宫格的最低标准

一张可测试的九宫格图片至少满足 4 条：

1. 3x3 结构清楚。
2. 每格都有明确主色。
3. 至少 6 格有饱满拼豆或图案，不是空盒。
4. 有一个明确的成品或操作暗示。
5. 缩小到朋友圈信息流尺寸仍能看懂主题。
6. 不依赖小字解释。

## 6. 素材生成提示词模板

下面提示词用于 Codex 生成素材 brief。真人只需要把 Codex 输出的提示词复制到图片或视频生成工具，再把结果交给 Codex 做筛选。

### 6.1 干净拼豆盒九宫格

用途：复刻当前强样本 `2178497` 的核心方向，但避免做成电商材料图。

```text
生成一张微信朋友圈广告图片，3x3 九宫格构图，每格是透明圆角拼豆收纳格，格内装满不同颜色的圆孔拼豆，颜色饱满、分类清楚、远看有强烈整理和配色满足感。画面是卡通写实风，不是商品摄影；背景干净明亮，整体温暖、轻松、解压。不要出现品牌、文字、水印、价格、购物感包装。图片应让用户联想到“把颜色整理好并完成拼豆图案”的小游戏。
```

负面提示：

```text
不要空盒，不要杂乱灰线，不要商品货架，不要价格标签，不要真实电商广告质感，不要过暗背景，不要复杂小字。
```

### 6.2 现实手作台 + 成品期待

用途：吸引手作熟悉用户，同时补上“最后能完成作品”的承诺。

```text
生成一张温暖黄色手作桌面场景，桌面上有拼豆收纳盒、白色拼豆底板、镊子和一个正在完成的可爱原创图案。构图中间保留清楚的 3x3 视觉节奏，左侧展示彩色拼豆，右侧展示即将完成的图案。画面轻松、干净、治愈，像休闲小游戏广告，不像材料商品售卖图。不要使用任何知名角色或品牌。
```

### 6.3 手部操作九宫格

用途：降低误吸，让用户知道这是“能玩、能点、能操作”的内容。

```text
生成一张 3x3 拼豆盒俯视图，九个格子里分别是不同颜色的圆孔拼豆，一只手拿镊子正在从其中一格取出拼豆放到中间的小底板上。画面要突出“取豆、放置、完成图案”的动作，背景简洁，颜色明亮。整体像轻松解压小游戏广告，而不是电商商品图。
```

### 6.4 纹身线稿九宫格

用途：测试成年女性审美、图案完成感和轻微挑战感。这个方向来自竞品黑白人物线稿九宫格，但必须避免像真正纹身广告。

```text
生成一张原创黑白细线稿拼豆图案九宫格，3x3 分割，每格是一部分成人审美线稿图案，例如花纹、首饰、人物局部、装饰线条，局部用红色、绿色、紫色拼豆点亮，形成“把黑白线稿逐步填成彩色拼豆作品”的感觉。画面精致、有手作感、轻微挑战，但必须像拼豆/涂色小游戏广告，不像纹身店广告。不要使用真实名人、品牌、名画原图或恐怖表情。
```

适合文案：

```text
这张图你能拼完整吗？
越拼越上头，停不下来
第一眼看懂的人不多
```

风险：

```text
如果画面太像纹身、太成人化或太惊悚，容易吸错人，也可能和轻松拼豆定位不匹配。上线前必须由 Codex 标记 adult_aesthetic 和 mismatch_risk。
```

### 6.5 游戏玩法承接图

用途：做真实玩法对照组，判断素材承诺和游戏体验是否匹配。

```text
生成一张竖版小游戏广告画面，上半部分是待完成的拼豆图案，下半部分是彩色拼豆槽位和手指点击操作，中间能看到“选择同色拼豆、放入暂存槽、点亮目标图案”的过程。画面干净，不要显得失败或很难。重点是让用户一眼明白这是轻松拼豆小游戏，不是实物材料广告。
```

### 6.6 竞品借鉴改写模板

当竞品某张素材出现次数高时，不直接抄图，按这个模板改写：

```text
竞品素材核心元素：[九宫格/手部/线稿/挑战文案/成品图案]
我们保留：[1-2 个核心心理钩子]
我们必须改掉：[颜色、题材、构图细节、角色、文案]
我们的游戏承接补充：[手部操作/游戏 UI/拼豆底板/目标图案]
生成方向：[具体提示词]
上线风险：[误吸/IP/玩法不清/过度挑战]
```

## 7. 测试计划 SOP

### 7.1 每日测试组合

默认每天只跑 3 组素材。当前日消耗只有几十元，不能同时铺太多组；如果当天预算低于 50 元，可以仍然准备 3 组素材，但只开 2 组，第三组次日轮换。

| 槽位 | 数量 | 来源 | 目的 |
| --- | ---: | --- | --- |
| 高先验复刻 | 1 | 历史相对强样本 + 竞品高频方向 + 用户画像一致 | 验证最可能成立的主方向 |
| 承接修正 | 1 | 历史高点击低回收或误吸风险方向 | 修正素材承诺和游戏真实体验的偏差 |
| 竞品先验探索 | 1 | 竞品热门但我方未充分验证的方向 | 扩展新素材池，但不当天放大 |

### 7.2 计划命名

```text
轻松拼豆-YYYYMMDD-[素材类型]-[核心元素]-[目标用户]-P-[序号]
```

示例：

```text
轻松拼豆-20260626-九宫图-干净色块-整理控-P-01
轻松拼豆-20260626-九宫图-手部取豆-真实操作-P-02
轻松拼豆-20260626-九宫图-线稿填色-审美挑战-P-03
```

### 7.3 单变量原则

同一轮测试只能改一个变量：

1. 只改画面元素，不改文案。
2. 只改文案，不改画面。
3. 只改题材，不改版式。
4. 只改是否出现手部操作，不改主图。

如果同时改题材、文案、颜色和版式，结果不可解释。

## 8. 指标和判定规则

### 8.1 公式

| 指标 | 公式 | 含义 |
| --- | --- | --- |
| CTR | 点击 / 曝光 | 外层吸引力 |
| CVR | 转化 / 点击 | 承诺和落地匹配 |
| CPA | 消耗 / 转化 | 获得目标成本 |
| ROI | 广告收入 / 消耗 | 最终买量质量 |
| 每点击回收 | ROI * 消耗 / 点击 | 点击质量 |
| 每转化回收 | ROI * 消耗 / 转化 | 目标用户质量 |

当前种子基准来自 2026-06-18 至 2026-06-25：CTR 约 6.90%，CVR 约 80.91%，首日加权 ROI 约 5.27。正式每日判断时，以最近 7 天同广告位 `P` 的加权均值为准。

### 8.2 小预算贝叶斯原则

当前每天只有几十元消耗，单日后验很弱。Codex 不能把某个素材一天的高 ROI 或低 ROI 当成确定结论，必须按“先验优先，后验校正”的方式判断。

先验来源按优先级排序：

1. 用户画像：87% 女性、30-50 岁为主，优先假设手作、整理、配色、解压、轻挑战有效。
2. 我方历史方向：不是看单条 ROI，而是看一类素材是否同时有消耗、点击、转化和合理 CPA。
3. 竞品热度：只能说明市场在复用某种表达，不能说明 ROI。
4. 游戏承接逻辑：素材必须让用户预期“这是拼豆小游戏”，避免只吸引买材料或看图的人。

后验使用规则：

| 情况 | Codex 判断 |
| --- | --- |
| 单日 ROI 很高，但点击 < 20 | 只增加一点信心，不放量 |
| 单日 ROI 为 0，但点击 < 20 | 不直接否定，继续看是否和先验冲突 |
| 连续 2-3 天都低 ROI，且 CPA 高于基准 | 才认为方向可能不适配 |
| CTR 高但 ROI 低 | 优先怀疑误吸或承诺不匹配，而不是只说素材好 |
| CTR 普通但 ROI 稳 | 优先保留，因为它可能吸来更准的人 |

### 8.3 样本置信度

| 等级 | 条件 | 允许动作 |
| --- | --- | --- |
| L0 冷启动 | 点击 < 20 或转化 < 10 | 只观察，不判死刑 |
| L1 可初判 | 累计点击 >= 30 且转化 >= 20，或累计消耗 >= 10 | 可暂停明显差素材，可复测好素材 |
| L2 可放量 | 累计点击 >= 100 且转化 >= 60，或累计消耗 >= 25，且至少覆盖 2 天 | 可小幅加预算 |
| L3 稳定 | 连续 2 天 ROI 和 CPA 达标 | 可进入主力素材池 |

### 8.4 动作规则

| 情况 | 判断 | 动作 |
| --- | --- | --- |
| ROI >= 基准 * 1.2，CPA <= 基准，L2 以上 | 候选强素材 | 小幅加预算，做 1 个同方向变体 |
| ROI 高但 L0/L1 | 小样本好 | 次日复测，不直接放量 |
| CTR 高，CVR 高，ROI 低 | 进来的人转化了但价值低 | 检查游戏内广告、留存、素材是否吸低价值用户 |
| CTR 高，CVR 低 | 外层吸引但承诺不匹配 | 改文案和玩法提示，或暂停 |
| CTR 低，CVR 高，ROI 高 | 人群准但吸引弱 | 保留核心，强化首图钩子 |
| CTR 低，CPA 高，ROI 低 | 全链路弱 | 暂停，不继续改小细节 |
| 竞品热度高但我方 ROI 低 | 市场热但不适配 | 只保留元素，不保留表达方式 |

## 9. 竞品分析 SOP

每天抓竞品前 20 个素材时，Codex 必须输出每个方向的收益和风险。

| 竞品方向 | 好处 | 风险 | 我方改写原则 |
| --- | --- | --- | --- |
| 现实拼豆盒九宫格 | 识别快，手作熟悉感强，适合女性用户 | 容易像材料电商图 | 加入游戏承接：目标图案、手部操作、完成反馈 |
| 彩色图案九宫格 | 成品期待强，容易停留观看 | 玩法解释弱 | 加一格操作过程或游戏 UI |
| 纹身/线稿九宫格 | 成人审美强，差异化明显 | 可能偏离轻松定位，误吸纹身/涂色兴趣 | 做成原创拼豆线稿，不做真实纹身广告 |
| 挑战文案 | 点击钩子强 | 太难会劝退主用户 | 文案轻挑战，画面保持轻松 |
| 手部操作 | 预期更准确 | 视觉不够漂亮时 CTR 低 | 和干净色块或成品图案组合 |
| 游戏 UI 画面 | 承诺真实，用户质量更稳 | 外层吸引力可能弱 | 只作为对照组或与强钩子混合 |

竞品只能借“心理钩子”和“版式逻辑”，不能复制具体图、角色、文字和商标。

## 12. 当前素材池的种子结论

这些结论只作为 SOP 初始配置，后续必须被每日 Excel 覆盖。

1. `999图/九宫图` 是当前最值得持续测试的图片大类，但要区分“干净色块秩序”和“材料收纳盒电商感”。
2. `2178497` 是当前后验相对更可信的样本，核心不是单纯收纳盒，而是干净、饱满、色彩秩序明确的拼豆九宫格。
3. `2178447` 说明相似题材也可能 ROI 为 0，不能机械复制。
4. `2234071` 说明漂亮成品图案不等于高 ROI，必须补玩法承接。
5. 竞品的九宫格、手部操作、线稿/纹身风、挑战文案都值得测试，但只能作为创意假设。

## 14. 禁止事项

1. 禁止只凭截图好看就放量。
2. 禁止只看 CTR 判断素材好。
3. 禁止直接复制竞品图片、文案、角色和商标。
4. 禁止把高 ROI 小样本直接当主力素材。
5. 禁止一天同时测试太多素材方向。
6. 禁止让素材承诺和真实游戏体验明显不一致。
