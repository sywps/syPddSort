# 轻松拼豆素材投放运营 SOP

> 版本：2026-06-25
> 适用：`轻松拼豆 / 拼豆豆` 微信小游戏朋友圈广告素材运营
> 目标：让 Codex 作为 AI 运营，自动完成素材诊断、竞品对照、测试建议和下一批素材生成文案；真人只负责 Codex 暂时无法直接执行的外部动作。

## 1. 运营目标

本 SOP 里的“运营”默认指 Codex 这个 AI 运营，不是指真人运营。真人只在 Codex 受限时补充输入，例如导出老后台 Excel、把提示词拿去生成图片、上传广告后台、提供登录态页面截图。

本 SOP 不把素材运营理解为“做几张好看的图”。它的目标是建立一套可重复执行的素材生产和投放判断流程：

1. 每天知道哪些老素材应该放量、保留、复测或暂停。
2. 每天知道下一批应该生成哪些素材，且每张素材都有明确目标用户和画面标准。
3. 每天能解释竞品热门素材为什么值得借鉴、为什么可能误导。
4. 每天用相同指标口径判断素材，不靠主观审美拍脑袋。

当前已知用户画像：女性约 87%，30-50 岁约 75%。因此素材默认服务“成年女性休闲、手作、整理、配色、解压、轻挑战”人群，不默认服务强竞技、硬核益智或年轻潮流用户。

## 3. 每日执行流程：Codex 自动跑

### 3.1 Codex 数据更新

1. Codex 优先读取已有抓取目录和当天 Excel。
2. Codex 自动筛选广告位 `P`，日期默认最近 7 天。
3. Codex 自动关联素材 ID、计划名、消耗、ROI、曝光、点击、转化和本地素材文件。
4. Codex 自动给每个素材打标签：素材类型、核心画面元素、文案承诺、目标用户、主要风险、下一步动作。
5. 如果浏览器登录态或后台限制导致 Codex 无法继续下载，真人只需要导出 Excel 或下载素材包，不参与分析判断。

### 3.2 启动 Codex 的话术

每天只要对 Codex 说：

```text
请按 docs/operate.md 跑今天的素材投放 SOP。
优先使用当前 temp 目录里已经抓到的我方素材、投放数据和竞品素材。
如果当天我补了 Excel 或新素材目录，请同时合并进去。
请输出：
1. 今天要放量/保留/复测/暂停的素材清单；
2. 每个判断的指标依据；
3. 竞品可借鉴点和风险；
4. 明天要生成的素材方案和提示词；
5. 每个新素材对应的测试计划。
```

### 3.3 真人只执行 Codex 无法直接执行的外部动作

1. Codex 给出素材组、提示词、负面提示、测试目标和计划名。
2. 真人把提示词拿去生成图片或视频。
3. 真人把素材上传广告后台。
4. 真人把生成后的素材文件和计划 ID 回传给 Codex。
5. Codex 次日自动复盘，不要求真人手工打标签。

### 3.4 次日：复盘

1. 不看单个指标，必须同时看 CTR、CPA、ROI、样本量。
2. 高 CTR 低 ROI 的素材先判为“吸错人”或“承诺不匹配”，不要直接放量。
3. 高 ROI 小样本只能复测，不能直接大幅加预算。
4. 连续两天低 ROI 且有足够消耗的素材暂停。

## 4. Codex 自动标签体系

每个素材必须打这些标签，但标签由 Codex 自动判断。真人不需要手工填写，最多在 Codex 判断不准时纠偏。

| 字段 | 示例 | 用途 |
| --- | --- | --- |
| 素材类型 | 九宫格图、竖版视频、玩法录屏、手作场景图 | 用于同类型对比 |
| 核心画面元素 | 拼豆盒、色块、手部操作、成品图案、游戏 UI、挑战文案 | 判断素材吸引什么人 |
| 文案承诺 | 解压、上头、挑战、整理、成品满足、第一关测试 | 判断是否和游戏体验匹配 |
| 目标用户 | 手作熟悉用户、整理控、配色审美用户、轻挑战用户、真实玩法用户 | 判断投来的人是否可能变现 |
| 主要风险 | 像电商材料、像涂色书、像纹身图、IP 风险、玩法不清楚 | 判断是否容易误吸 |
| 下一步动作 | 放量、保留、复测、改图、暂停 | 投放执行 |

### 4.1 朋友圈广告三件套

朋友圈广告不是裸图测试。Codex 判断和生成时必须把一个投放单元拆成三件套：

| 部件 | 作用 | 默认权重 |
| --- | --- | ---: |
| 正文钩子 | 决定用户是否理解“为什么要点”，负责挑战、解压、代入和好奇心 | 50-60% |
| 图片 | 负责停顿、证明玩法、降低误吸；图片差会放大低质点击 | 20-30% |
| 链接条/首条评论 | 负责社会证明、降低广告感、补充“别人也在玩”的理由 | 15-25% |

用户提出的 `正文 60% / 评论 20% / 图片 20%` 可以作为当前强先验，但 Codex 不能机械套用。实际判断时：

1. 如果正文很强但图片承诺错，会出现 CTR 高、ROI 低。
2. 如果图片好但正文没有钩子，会出现曝光够但点击弱。
3. 如果评论/链接条像真实玩家反馈，可以提高点击后的心理承接。
4. 图片内不要写字，文字钩子放在朋友圈正文、链接条和评论里。

两张真实朋友圈广告给出的启发：

| 样本 | 正文钩子 | 图片作用 | 评论/链接条作用 | 对轻松拼豆的启发 |
| --- | --- | --- | --- | --- |
| 解压高手 | “能过 5 关算你牛” | 密集找物图制造挑战感 | “已玩，已解压”“超过 1.4 万人在玩”制造社会证明 | 可测轻挑战：这 9 格你能拼完整吗 |
| 撕个胶带 | “一个人能安静地撕一下午” | 大量可撕元素制造时间消耗感 | “我很菜，但我爱撕”“我奶奶竟然干到榜一了”制造代入 | 可测解压陪伴：一个人能安静地拼一下午 |

## 5. 画面元素标准

### 5.1 当前正向元素

从当前已抓我方素材和竞品素材看，优先测试这些元素：

1. 干净九宫格：3x3 分区清楚，每格颜色饱满，远看一眼能懂“分类、整理、配色”。
2. 拼豆质感：珠子有孔洞、圆角、轻微高光，不能像普通糖果或积木。
3. 色彩秩序：每格主色明确，最好有渐变、冷暖对比或彩虹序列。
4. 成品期待：能看到花朵、角色、图案、装饰画等完成结果。
5. 手部动作：镊子、手指、取豆、放豆，能解释“这是可操作的小游戏”。
6. 轻挑战文案：比如“这关你能过吗”“第一关别卡住”，但不能把画面做得太难。

### 5.2 当前负向元素

这些元素需要谨慎：

1. 只像收纳盒或材料商品，没有游戏感，容易吸引买材料的人。
2. 过多灰线、空格、半透明盒边，远看杂乱。
3. 只有漂亮成品，没有操作、目标或玩法提示。
4. 明确 IP 角色、商标角色、名画原图，存在版权和审核风险。
5. 过度困难、失败、槽位爆满的画面，会带来低质量好奇点击。

### 5.3 好九宫格的最低标准

一张可测试的九宫格图片必须先满足结构标准：

1. 图片内部只有一个标准 3x3 九宫格。
2. 必须是 3 列 x 3 行，正好 9 个等大的格子。
3. 不能是一格大特写，不能是左右分栏玩法图，不能是一张图里放多个九宫格。
4. 不能有第二块棋盘、额外调色盘、嵌套小九宫格或四宫格拼贴。

通过结构标准后，再判断画面质量：

1. 每格都有明确主色或明确图案进度。
2. 至少 6 格有饱满拼豆或图案，不是空盒。
3. 有一个明确的成品、整理或操作暗示。
4. 缩小到朋友圈信息流尺寸仍能看懂主题。
5. 不依赖小字解释。

### 6.1 干净拼豆盒九宫格

用途：复刻当前相对可信样本 `2178497` 的核心方向，但避免做成电商材料图。

这是单张方图，图片内部必须只有一个标准 3x3 九宫格。不是 9 张独立图，不是一格大特写，不是一张图里放多个九宫格。

重要修正：不要生成真实珠子收纳盒的宏观摄影。失败样本表现为“真实透明盒 + 大量实物珠子 + 产品图质感”，这会把用户引到材料购买心智。正确方向是“Cocos 休闲游戏风的拼豆颜色关卡切片”，有拼豆质感，但不是实拍材料。

### 6.2 现实手作台 + 成品期待

用途：吸引手作熟悉用户，同时补上“最后能完成作品”的承诺。

重要修正：这个方向只能保留“手作熟悉感”，不能生成真实木桌、植物、阳光手作摄影。失败样本看起来像手作材料商品图，不适合作为小游戏买量素材。

```text
交付物：
生成一张 1024x1024 正方形微信朋友圈广告图，用于休闲小游戏《轻松拼豆》。图片内不要出现任何文字。

目标用户与点击理由：
目标用户是 30-50 岁女性，喜欢手作、温和装饰和完成一个小作品的满足感。图片要借用现实手作的熟悉感，但最终承诺必须是“我可以在小游戏里轻松完成一个拼豆图案”。

画面场景：
画面是风格化休闲游戏手作棋盘，不是真实桌面摄影。展示一个简单圆角游戏棋盘，棋盘上有一个正在完成的原创可爱拼豆图案。旁边可以有一个紧凑的颜色选择面板，但它必须像游戏界面，不像实物材料盒。图案可以是原创小花、爱心、蝴蝶、小水果或抽象挂件，不要任何知名版权角色。

验收标准：
```

### 6.3 手部操作九宫格

用途：降低误吸，让用户知道这是“能玩、能点、能操作”的内容。

重要修正：不要生成真实手、真实镊子和真实桌面。用“游戏里的手指指示器 / 触控光标”表达操作，否则会变成手作摄影。

```text
交付物：
生成一张 1024x1024 正方形微信朋友圈广告图，用于休闲小游戏《轻松拼豆》。图片内部必须是一个完整的 3x3 九宫格棋盘：三列、三行、正好 9 个等大格子。图片内不要出现任何文字。

目标用户与点击理由：
目标用户是需要快速看懂玩法的用户。图片要表达“这是能点、能移动、能完成图案的小游戏”，而不是“这是拼豆收纳商品”。

画面场景：
俯视角风格化手机游戏棋盘。画面只有一个圆角正方形棋盘，棋盘分成正好 9 个等大格子。每个格子里有拼豆或部分图案进度。一个简化的游戏手指光标或点击光效，正在把一颗拼豆从某一格移动到正中格的目标位置。

整体构图：
```

## 8. 指标和判定规则

### 8.1 公式

| 指标 | 公式 | 含义 |
| --- | --- | --- |
| CTR | 点击 / 曝光 | 外层吸引力 |
| CVR | 转化 / 点击 | 承诺和落地匹配 |
| CPA | 消耗 / 转化 | 获得目标成本 |
| ROI | 广告收入 / 消耗 | 最终买量质量 |
| 每点击回收 | ROI * 消耗 / 点击 | 点击质量 |
| 每转化回收 | ROI * 消耗 / 转化 | 目标用户质量 |

当前种子基准来自 2026-06-18 至 2026-06-25：CTR 约 6.90%，CVR 约 80.91%，首日加权 ROI 约 5.27。正式每日判断时，以最近 7 天同广告位 `P` 的加权均值为准。

### 8.2 小预算贝叶斯原则

当前每天只有几十元消耗，单日后验很弱。Codex 不能把某个素材一天的高 ROI 或低 ROI 当成确定结论，必须按“先验优先，后验校正”的方式判断。

先验来源按优先级排序：

1. 用户画像：87% 女性、30-50 岁为主，优先假设手作、整理、配色、解压、轻挑战有效。
2. 我方历史方向：不是看单条 ROI，而是看一类素材是否同时有消耗、点击、转化和合理 CPA。
3. 竞品热度：只能说明市场在复用某种表达，不能说明 ROI。
4. 游戏承接逻辑：素材必须让用户预期“这是拼豆小游戏”，避免只吸引买材料或看图的人。

后验使用规则：

| 情况 | Codex 判断 |
| --- | --- |
| 单日 ROI 很高，但点击 < 20 | 只增加一点信心，不放量 |
| 单日 ROI 为 0，但点击 < 20 | 不直接否定，继续看是否和先验冲突 |
| 连续 2-3 天都低 ROI，且 CPA 高于基准 | 才认为方向可能不适配 |
| CTR 高但 ROI 低 | 优先怀疑误吸或承诺不匹配，而不是只说素材好 |
| CTR 普通但 ROI 稳 | 优先保留，因为它可能吸来更准的人 |

### 8.3 样本置信度

| 等级 | 条件 | 允许动作 |
| --- | --- | --- |
| L0 冷启动 | 点击 < 20 或转化 < 10 | 只观察，不判死刑 |
| L1 可初判 | 累计点击 >= 30 且转化 >= 20，或累计消耗 >= 10 | 可暂停明显差素材，可复测好素材 |
| L2 可放量 | 累计点击 >= 100 且转化 >= 60，或累计消耗 >= 25，且至少覆盖 2 天 | 可小幅加预算 |
| L3 稳定 | 连续 2 天 ROI 和 CPA 达标 | 可进入主力素材池 |

### 8.4 动作规则

| 情况 | 判断 | 动作 |
| --- | --- | --- |
| ROI >= 基准 * 1.2，CPA <= 基准，L2 以上 | 候选强素材 | 小幅加预算，做 1 个同方向变体 |
| ROI 高但 L0/L1 | 小样本好 | 次日复测，不直接放量 |
| CTR 高，CVR 高，ROI 低 | 进来的人转化了但价值低 | 检查游戏内广告、留存、素材是否吸低价值用户 |
| CTR 高，CVR 低 | 外层吸引但承诺不匹配 | 改文案和玩法提示，或暂停 |
| CTR 低，CVR 高，ROI 高 | 人群准但吸引弱 | 保留核心，强化首图钩子 |
| CTR 低，CPA 高，ROI 低 | 全链路弱 | 暂停，不继续改小细节 |
| 竞品热度高但我方 ROI 低 | 市场热但不适配 | 只保留元素，不保留表达方式 |

## 9. 竞品分析 SOP

每天抓竞品前 20 个素材时，Codex 必须输出每个方向的收益和风险。

| 竞品方向 | 好处 | 风险 | 我方改写原则 |
| --- | --- | --- | --- |
| 现实拼豆盒九宫格 | 识别快，手作熟悉感强，适合女性用户 | 容易像材料电商图 | 加入游戏承接：目标图案、手部操作、完成反馈 |
| 彩色图案九宫格 | 成品期待强，容易停留观看 | 玩法解释弱 | 加一格操作过程或游戏 UI |
| 纹身/线稿九宫格 | 成人审美强，差异化明显 | 可能偏离轻松定位，误吸纹身/涂色兴趣 | 做成原创拼豆线稿，不做真实纹身广告 |
| 挑战文案 | 点击钩子强 | 太难会劝退主用户 | 文案轻挑战，画面保持轻松 |
| 手部操作 | 预期更准确 | 视觉不够漂亮时 CTR 低 | 和干净色块或成品图案组合 |
| 游戏 UI 画面 | 承诺真实，用户质量更稳 | 外层吸引力可能弱 | 只作为对照组或与强钩子混合 |

竞品只能借“心理钩子”和“版式逻辑”，不能复制具体图、角色、文字和商标。

## 13. Codex 每日检查清单

Codex 在输出素材方案前必须自检：

- [ ] 这张素材的目标用户写清楚了吗？
- [ ] 画面缩小后还能看懂吗？
- [ ] 是否至少有 4 条九宫格最低标准？
- [ ] 是否像游戏广告，而不是材料商品广告？
- [ ] 是否避免了明确 IP、商标和名画原图？
- [ ] 是否只改变了一个测试变量？
- [ ] 计划名是否能看出素材类型、核心元素和目标用户？

Codex 在复盘时必须自检：

- [ ] 样本量是否达到 L1 或 L2？
- [ ] CTR、CVR、CPA、ROI 是否同时看了？
- [ ] 高 CTR 低 ROI 是否被标记为误吸风险？
- [ ] 高 ROI 小样本是否只安排复测，没有直接放量？
- [ ] 竞品热度是否只作为灵感，没有当成 ROI 证据？

## 14. 禁止事项

1. 禁止只凭截图好看就放量。
2. 禁止只看 CTR 判断素材好。
3. 禁止直接复制竞品图片、文案、角色和商标。
4. 禁止把高 ROI 小样本直接当主力素材。
5. 禁止一天同时测试太多素材方向。
6. 禁止让素材承诺和真实游戏体验明显不一致。
