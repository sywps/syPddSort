## 你在后台需要做的事

1. 在「消息订阅」确认新模板名称是「版本更新提醒」，关键词包含「更新内容」。官方模板库编号是 13715；这是模板类型编号，与后台生成的 MSG 编号不同。
2. 先在新版游戏的设置里主动点击「订阅版本更新提醒」，真机确认弹出抖音授权，只有同意才显示订阅成功。拒绝不影响游戏。平台自动退出订阅引导是另一入口：官方开通规则还列出「任务完成提醒」模板（13727），若需要该自动引导再对照控制台核对；本次客户端仅请求版本更新模板，不混合请求其他模板。
3. 游戏处于「已发布」状态后，在版本更新提审页面开启「抖音更新提醒」，填写与本次更新相符的提醒内容，再提交审核。文案例如「优化游戏体验，修复已知问题」，仅在确有相应改动时使用。

由平台向符合条件且主动订阅的用户发送，不保证每次更新都通知所有人，也不是保存模板后立即发送。官方规则对同一用户每周最多推送一次。
