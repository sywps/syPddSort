# CSD 正式版检查口径（2026-09-16）

本次为本地实现，未部署云函数、未构建/发布正式客户端。不存在新增玩家提示、弹窗、等待层、重试入口或自动跳过引导。

## 采集边界

使用微信运行时 `miniProgram.envVersion=release` 与设备平台白名单确认正式运行；开发者工具、体验/开发版本、浏览器、无法识别环境均不入队、不持久化待上传记录、不发送。
门槛只针对统计，保留登录、存档和实验配置等原有业务行为。使用正式客户端进行人工测试仍属于正式版数据，不做测试人员身份识别。
`analyticsEnvironment=wechat_release`、`csdVersion=3` 为新版口径标识；不是防伪签名。服务端拒绝显式标记 v3 但环境不符的记录，同时保留旧客户端兼容。
正式队列、引导计数、局状态及运行检查点使用独立 release.v3 存储键。旧键原样保留、不导入，避免来源未知的旧缓存补传；不清除玩家存档和历史云数据。

## 被动诊断与游戏圈

输入检查利用现有 update 每 0.5 秒最多一次观察，仅主线前十关、正式采集开启时工作；不逐帧上传。正常开场不当作持续故障，后台不累计，设置/广告/道具/结算等预期阻挡不计入故障片段。采样不能精确覆盖两个采样点之间的短暂变化；观察中断不标永久卡死。
首关 AFTER_DRAW 超时只在前台检查，后台返回可重新订阅；结算后不检查棋盘是否可点击，旧局回调受代次保护。
游戏圈 Cocos EnterBtn 保留外观与布局、取消交互和合成异常；面板动画完成后，在绘制完成阶段创建原生按钮，后续同步位置。背景、被覆盖、关闭和销毁清理原生按钮及监听。无额外 Toast/重试 UI。仅本地模拟原生边界测试通过，仍须微信真机验证实际覆盖与打开行为。
冰冻使用次数在计时效果应用处递增，不再放在可选视觉操作之后；未修改冰冻时长、免费政策或关卡难度。

## 日报与历史兼容

主线归属采用明确字段、同局或同会话同关卡唯一可判定关联，主题和无法判定者不混入；未知归属数单独列出。
新旧环境口径不混算。有 v3 正式记录时，CSD 区只统计正式记录；仅有历史记录时标“历史环境未知”，新版缺失项显示“未采集”。原有兼容日报区域不冒充新版正式口径。
广告入口、实际展示信号、最终完成与奖励分开；原生 show 回调不是平台结算曝光。失败、主动中止、缺失结局仍分别展示，不改写历史原始数据。
本次对 9 月 15 日只读回放保持主线前五关进入局数 369/239/206/50/32；旧扩容入口分类未知次数 0/27/63/4/0。回放结果在 `.planning/first5-20260915/csd-replay.json`，未覆盖原日报。
