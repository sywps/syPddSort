# 无广告网页版

对外名称为“无广告版”，页面标题为“拼豆游戏 · 无广告版”。下文历史记录中的“达人版”指同一构建；内部构建目录和存档标识保持原值，避免影响既有存档。

## 构建与交付

运行 `npm run build:creator-web`，使用本机 Cocos Creator 3.8.8（也可通过 `COCOS_CLI` 指定）。输出在 `build/creator-web/`，与微信、抖音和普通 Web 构建目录分开。

`node scripts/build-creator-web.js --prepare-only` 只生成临时 Cocos 构建配置，不启动构建。配置源为 `tools/creator-web-build-config.json`。

交付时需要上传整个输出目录到支持 HTTPS 的静态网站托管；本次不含公网部署。浏览器通过 HTTP/HTTPS 打开，不能双击 index.html 以 file 协议运行。公网域名、移动网络、微信/抖音内置浏览器和 iOS 真机仍需部署后验证。

## 行为

- 启动进入首页，在开始按钮下显示关卡输入框。输入有效编号时更新开始按钮上的关卡号，点击原开始按钮才进入；无效编号会提示并阻止开始。
- 主线范围来自构建时的真实 `assets/LevelData/level_*.json` 文件；无效编号不跳转。
- 达人版开始、重试、下一关不扣体力，即使原存档体力为 0 也可进入。首页体力栏保持原数字、满体力/恢复倒计时和原有体力面板，不显示“无限体力”或∞，不改变存档数值。开始/重试/下一关的扣体力标记保持隐藏。普通预览、微信和抖音仍用原体力规则。
- 保留原有广告按钮及奖励数量。点击广告直接完成现有预览成功回调，由原奖励事务发放金币、道具、复活等；不等待视频，不调用原生广告。
- 复用浏览器预览的奖励存档/章节奖励规则；跳关选择与实际完成列表分开，首页不把跳过的关卡画成已完成。
- 选关、金币、道具、皮肤、体力和设置使用 `pdd.creator-web.v1:` 命名空间，刷新保留；不读取或覆盖同域普通网页版/Cocos 预览存档。清理网站数据会清除达人存档。
- 本达人版不接入云端存档，不上报正式埋点。存档属于当前浏览器和站点，换设备/换浏览器不会同步。
- 跳关区域恢复棕色常规文字；只有输入数字为黑色加粗，水平/垂直居中。数字框宽度100（原140），白底、3单位棕色轮廓，两侧文字内收。不再有单独的“进入”按钮。
- 首页和设置中的问题反馈入口在达人版隐藏。达人图鉴全部彩色、可点击预览，顶部显示“可预览”数量；主线/像素详情按钮显示“体验本关”并隐藏体力消耗。合作图鉴预览只读取目录/图案，不请求云端完成记录。以上不写入已收集或通关状态、不发奖励，主页九宫格仍由实际完成列表控制。
- 达人标记仅由专用 HTML 启动脚本注入，微信/抖音运行时不启用；正式统计沿用预览模式的禁用逻辑。
- 按最新决定恢复随网页打包的关卡：第一关读取 bootstrap，其余关卡和图鉴读取 levelData Bundle。构建取项目当时的关卡内容，不注入 OSS 地址、不依赖远程关卡 CDN/CORS。资源加载失败仍明确报错。
- 头像、框、皮肤及其他资料也随包发布，存档仍为浏览器本地隔离存档。网站部署到公网后照常通过链接游玩，不要求局域网。更新关卡需要重新构建并发布网页。
- 之前尝试的 v2 A CDN 因 CORS 被浏览器拦截，该方案已被随包方案取代；无需修改 OSS 跨域规则，本任务没有改过 OSS 配置或上传资源。
- 浏览器拒绝持久化时停止游戏启动并显示错误，不退回普通存档空间。

## 构建边界

构建复用项目已有的 `normalize-minigame-pack-indices.js` 和 `patch-bootstrap-dynamic-assets.js` 的资源提取工具，校验 release pack 索引、补齐 Cocos 跨 Bundle 自动图集依赖和 CCON 动画扩展名映射，只处理达人版输出目录。显式关闭小游戏专用 WASM 分包/手动 Spine 加载，允许网页引擎正常初始化动画。

此次不新增联机、排行榜、平台登录等网页版服务；达人版首页隐藏 PK 对战入口，其余既有入口与预览行为保持一致。
